# Roadmap maintenance

`ROADMAP_PROGRESS.md` is the canonical cross-program roadmap index. Detailed status and authority boundaries belong in focused files in this directory.

Current unnumbered-package references:

- `exercise-preferences-smart-replace.md` — Exercise Preferences + Smart Replace; custom-template UI is the active package;
- `exercise-training-intelligence-expansion.md` — completed Exercise & Training Intelligence expansion;
- `adaptive-program-recovery.md` — completed Adaptive Program + Recovery A1–A4 package;
- `next-product-expansions.md` — reviewed queue after the current Smart Replace package.

Update rules:

- edit only the relevant focused file for ordinary status changes;
- update `ROADMAP_PROGRESS.md` when priorities, phase ownership, package status or file structure changes;
- update `docs/implementation-plan.md`, `docs/current-status.md` and `docs/handoffs/latest.md` when forward execution/restart state changes materially;
- record completed PR numbers, exact-head CI evidence and merge SHAs in the owning focused roadmap file;
- do not copy full historical implementation logs into the index;
- do not invent P21-F/Phase 22 merely to continue development;
- Git history remains the archive for superseded roadmap wording.
